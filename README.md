# Afterglow Getaway

A browser driving game with live gameplay telemetry, a Python API, and SQLite storage.

Explore an original coastal city on foot or in a pink coupe, avoid traffic, and complete a two-stop delivery mission. The current in-game city is called Neon Coast.

## Run locally

Requires Python 3.10+ and a modern browser. No third-party packages or API keys required.

```sh
git clone https://github.com/RichaShiny/afterglow-getaway.git
cd afterglow-getaway
python3 server.py
```

Open http://localhost:5174 and choose **Start your night**. Keep the terminal running. Press Ctrl+C to stop the server.

## Controls

| Key | Action |
| --- | --- |
| W / S or Up / Down | Walk, accelerate, or reverse |
| A / D or Left / Right | Walk sideways or steer the car |
| E | Enter or exit the car nearby |
| Space | Brake |
| P | Pause or resume |

Steering responds at a standstill. Hold W+A or W+D to drive through a turn. Slow down inside each golden mission marker.

## Live gameplay data

Click **Live data** to view local session stats and the server feed. The game records position approximately twice per second of active simulation, plus session starts, restarts, vehicle entry/exit, collisions, and mission checkpoints. A browser queue sends batches every second. UUID event IDs prevent duplicate inserts on retries.

- `POST /api/events`: accepts a session UUID and up to 100 gameplay events.
- `GET /api/live`: returns saved event/session counts and the 12 most recent events.
- `runtime/telemetry.sqlite3`: persistent local event database, created automatically and excluded from Git.

Refreshing starts a new session; saved history remains in SQLite. Unsent browser events are held only in memory and may be lost on refresh. Offline uploads retry while the page remains open. The feed contains real actions in this game; traffic and the city are generated by code. No external game feed or ML detection model is connected.

## Project layout

```text
dist/index.html     Game interface and HUD
dist/game.js        Canvas rendering, gameplay, and event generation
dist/telemetry.js   Upload queue, connection status, and live feed
server.py           Local HTTP API, static server, and SQLite persistence
```

This is a single-player 2D prototype. The Python server binds to loopback for local development; it does not provide production authentication or multiplayer. GitHub Pages alone can serve the visuals but cannot run the Python API or SQLite backend.
